# 仓库来源说明

本仓库（[FrozenYears/dogsc-for-windows](https://github.com/FrozenYears/dogsc-for-windows)）是 DogSC 的 Windows 原生实现，**不是**上游 macOS 项目的 fork。

- 上游：<https://github.com/laogou717/dogsc>（MIT，Copyright (c) 2026 神烦老狗）
- 建仓时远程仓库曾包含一份 macOS 源码快照（commit `567fd6e`），该内容与上游一致，已由本仓库的规划文档提交覆盖；需要源码参照时请直接查看上游仓库。
- 本仓库与上游**不做工程文件互通**：Windows 端是独立的软件系统（见 `15-final-plan.md` §1）。

保留此说明是为了让内容变更可追溯：`567fd6e` 的内容仍在上游仓库完整可得。
