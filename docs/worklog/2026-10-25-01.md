# 2026-10-25 第 01 轮：P1b draft session、自动保存与关闭保护

## 目标

在 P1a 的立即写盘模型上建立真实 draft session：编辑先写 `.project-draft.json`，自动保存去抖后发布到 `project.json`，提供 flush、失败重试、discard 和关闭保护。

## 完成

- Native 新增 project session 命令：
  - `project begin`：创建/恢复 `.project-draft.json`；
  - `project edit-draft`：只修改 draft；
  - `project save`：把 draft 通过现有 history/原子替换发布；
  - `project discard`：删除 draft 并重载正式工程。
- Tauri 编辑器新增保存状态、保存、放弃草稿按钮。
- 每次编辑进入草稿后 800ms 去抖自动保存；保存失败最多重试一次；切换工程、重命名、撤销/重做前会 flush。
- `beforeunload` 在 native 命令执行中或 draft dirty 时阻止无提示离开。
- `ProjectSnapshot.session.dirty` 由 native 返回，不能由前端 UI 文本推断。

## 决议

- P1b 仍是部分完成：自动保存、flush、失败重试、discard 和 beforeunload guard 已接入；崩溃恢复清单、真实 Tauri 关闭确认和完整编辑器事务仍未关闭。
- 不把“立即写盘”或按钮状态当作崩溃恢复；draft 文件与 project history 必须继续由 native 管理。

## 证据

- native Release clean build：成功。
- CLI session smoke：`begin` dirty=false；`edit-draft split` dirty=true 且正式 `project.json` 未改变；`save` dirty=false 且正式工程变为 edited；draft 文件删除。
- 最新 Tauri GUI 安装包：打开工程显示“已保存”；点击 split 后约 350ms 显示“待保存”、保存按钮可用；等待自动保存后显示“已保存”、保存按钮禁用。
- 旧工程编辑器、P1a 多步 history、P2a/P2b 预览链路保持可构建。
