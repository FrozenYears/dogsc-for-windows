# 2026-10-25 第 18 轮：P6 可重复硬件矩阵脚本

## 目标

把当前机长时采集和编码器枚举固化为可在其他 Windows 机器重复执行的 P6 脚本，避免只保留人工命令和散落日志。

## 完成

- 新增 `tests/p6-capture-matrix.ps1`，可配置 executable、显示器、帧率、时长、codec、系统音频和重复帧阈值。
- 脚本自动保存编码器枚举、capture.json、ffprobe 媒体信息和结构化 `p6-matrix-report.json`。
- 脚本强制校验 finalized、期望输出帧数、非单调丢帧为 0、重复帧阈值、系统音频 48kHz/2ch 和媒体视频帧数。
- 更新 Release/长时矩阵状态。

## 决议

- 当前默认重复帧阈值为 1000，不能把“输出帧数正确”误报为采集端无重复；报告保留 captured/repeated 原始值。
- 脚本在当前 NVIDIA 机器通过，不代表 4K60、AMD/Intel、无硬件编码器、休眠恢复或跨设备通过。
- 不自动删除回归产物；报告和媒体留在 `out/smoke` 供后续复核。

## 证据

- PowerShell parser：`tests/p6-capture-matrix.ps1` syntax OK。
- `p6-capture-matrix.ps1` 60s run：2560×1600@60、NVIDIA HEVC MFT、3600 输出帧、3521 captured、330 repeated、0 discardedNonMonotonic、0 system audio discontinuity。
- 报告同时记录 AMD HEVC/H.264 激活失败、NVIDIA HEVC/H.264 激活成功、软件 HEVC/H.264 与 FFmpeg ProRes 条目。
- 脚本报告已经执行 ffprobe 校验视频帧数及系统音频采样率/声道。

## 遗留

- P6：4K60、AMD/Intel/无硬件编码器、跨设备、多轮长时、休眠恢复和最终法律材料。
- P2b：实际显示撕裂和刷新率矩阵缺外部捕获证据。

## 下一步

- 将脚本作为各硬件环境的统一入口；在当前环境不具备 4K/第二 GPU 时保留 P6 partial，不外推结论。
