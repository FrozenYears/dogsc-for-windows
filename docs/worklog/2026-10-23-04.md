# 2026-10-23 第 04 轮：M0 核心层开工

## 目标

按 `15-final-plan.md` §7 启动 M0：建 CMake 骨架，移植决定成片帧数与音画同步的三个核心模块，完成工程 JSON 编解码与逐帧场景快照工具。

## 完成

- **构建骨架**：`CMakeLists.txt`（C++20、MSVC `/W4 /permissive- /fp:precise /Zc:__cplusplus /utf-8`）、`cmake/Dependencies.cmake`（vcpkg 优先，缺失时 FetchContent 拉 nlohmann/json 3.11.3）、`vcpkg.json`、`.clang-format`（LLVM 基座，4 空格，100 列）。
- **核心层 `src/core/`**（11 个实现文件 + 12 个头文件）：
  - `output_frame_schedule`：90,000 时基、整数 tick 网格、端开区间、ulp 级边界吸附。
  - `timeline_map`：`RecordingSegment` 无 `outputStart`，输出位置由累加推导；六类错误逐条对齐上游。
  - `timeline_media_plan`：主/辅助轨切片、切点边界容差 `1e-9`、锚点曲线校正。
  - `media_timeline`：`MediaTimelinePlacement` 与 `MediaSyncAnchorCurve`。
  - `project_timeline`：`TransitionTiming` enter/hold/return、贝塞尔缓动（Newton + 二分）、元素运动曲线。
  - `project_model`：schema 23…27 校验、画布像素尺寸推导（偶数化、裁剪包络、不放大）。
  - `project_json`：`ProjectJson::decode/encode`，缺省即默认、未知字段忽略、写盘固定当前版本。
  - `frame_scene_evaluator`：开场采样（聚拢/侧滑/轻 3D）、overlay 进度、图层顺序派生。
  - `frame_compositor`：`IFrameCompositor` 契约 + `is_valid_layer_order` 规范顺序校验。
  - `cursor_asset`：`CursorAssetID` 系统目录 + 热点锚定布局。
  - `timing_guards`：三条不可事后修复的时序契约（首帧归一、非单调 PTS 丢弃、共享 stop host-time）。
- **测试** `tests/core_tests.cpp`：32 个用例，覆盖帧数与 PTS、切点无缝、重叠/越界拒绝、播放速率、JSON 往返与缺省、schema 拒绝、图层顺序、开场名单稳定性、光标热点、画布尺寸、时序护栏。
- **工具** `tools/scene_dump`：工程 + 时长 + 帧率 → 逐帧 JSON；两次运行输出逐字节相同。

## 决议

- C++ 命名采用 `snake_case` + `k` 前缀枚举，与上游 Swift 的类型语义一一对应，不做额外抽象。
- `OutputFrameSchedule` 增加默认构造函数以便测试构造；构造逻辑仍在 `create()` 中，保持「失败不产生半成品」的语义。
- 时序契约抽成 `TimingGuards` 纯函数而非散落在采集层，使采集与导出共用同一判定。
- 本产品不与 macOS 互通，`CursorAssetID` 只保留系统语义值，不复制已退役的自绘光标 ID。

## 证据

- 干净重建：`cmake --build build --config Debug --parallel --clean-first` 退出码 0，错误与警告计数均为 0。
- 测试：`ctest --test-dir build -C Debug` → `100% tests passed, 0 tests failed out of 1`（可执行内含 32 个用例）。
- 工具：`scene_dump` 对同一工程两次运行 `cmp` 相同（563 字节）；错误路径验证 —— 帧率 45 返回 4，schema 22 返回 3 并输出「项目版本 22 过旧」。
- 源码参照：`OutputFrameSchedule.swift`、`TimelineMap.swift`、`TimelineMediaPlan.swift`、`ProjectModel.swift`、`ProjectMediaModel.swift`、`FrameScene.swift`、`ZoomAnimation.swift`、`ScreenCaptureOutput.swift:430-520`、`AppModel.swift:737-760`。

## 遗留

- `scene-dump` 目前只输出帧时间与图层顺序；完整 `FrameScene` 字段（屏幕几何、摄像头、贴图、光标位置）需在 M2a 前补齐，届时才有像素级基准可对。
- `[INFERENCE]` 上游 `ProjectSchema` 的 v1–v22 迁移路径尚未移植；M0 只处理 23…27，旧版本一律拒绝并给出明确错误。
- JSON 编解码采用手写字段映射（未引入反射），新增字段时需同步三处：结构体、`decode`、`encode`。
- 构建依赖 FetchContent 下载 `nlohmann/json`，离线机器首次配置会失败；接入 vcpkg 清单模式后消除。
