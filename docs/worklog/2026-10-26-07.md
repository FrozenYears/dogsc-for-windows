# 2026-10-26 第 26 轮：手动缩放关键帧 UI/native 切片

## 目标

继续实现不依赖额外硬件或法律输入的原版功能：将核心层已有 ZoomClip 求值能力接入 Tauri 检查器和 native 工程编辑命令。

## 完成

- `dogsc_capture project edit ... zoom` 新命令：
  - start
  - duration
  - focus-x / focus-y
  - scale
  - enter / exit duration
- 通过 `ProjectTimelineEditing::inserting_zoom` 写入 `timeline.zoomClips`，不在 TypeScript 重复工程写盘逻辑。
- Tauri inspector 增加缩放关键帧控件和“添加”操作。
- 缩放 UI 输入会进入同一 dirty draft、自动保存、撤销/重做和 D2D preview pipeline。
- GUI smoke 增加 `DOGSC_EXERCISE_ZOOM=1`，验证 zoom clip 自动保存后继续完成预览生命周期。

## 决议

- 本轮实现“手动缩放关键帧”而不是伪造原版 AutoZoomPlanner；点击聚类自动生成仍保留为明确遗留。
- 缩放使用 native `ProjectTimelineEditing` 与现有 `ZoomAnimationTrack`，保持项目 JSON 和逐帧求值单一真相。
