# 2026-10-25 第 05 轮：P1b 原生关闭请求拦截

## 目标

将编辑器关闭保护从 WebView `beforeunload` 提示，提升到 Tauri 窗口关闭请求事件；dirty 工程要先确认，确认后 flush 保存成功才可关闭。

## 完成

- 使用 Tauri v2 `getCurrentWindow().onCloseRequested` 订阅原生关闭请求。
- 无 dirty draft 且没有工程命令执行时允许直接关闭。
- 操作进行中时阻止关闭并提示等待。
- dirty draft 时显示保存并关闭确认；取消留在编辑器；确认后调用既有 `flushProjectSave()`，保存失败则保留窗口，成功后通过 `destroy()` 完成关闭。
- 移除 `beforeunload` guard，避免依赖浏览器对 unload 提示的实现差异。

## 决议

- dirty 状态仍由 native project session snapshot 提供；本轮不另造前端 dirty 标记。
- 只提供“保存并关闭/取消”两条路径；丢弃草稿仍由编辑器已有 discard 操作显式执行。
- P1b 仍未完成：关闭对话框分支的完整自动化验收、恢复清单启动选择与脏事务边界测试待补。
