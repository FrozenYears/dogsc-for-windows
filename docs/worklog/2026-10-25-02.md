# 2026-10-25 第 02 轮：P4 单源视频导出 prototype

## 目标

把 SourceReader、FrameSceneEvaluator、D2D/WARP/硬件合成器和 MediaWriter 串成第一条真实导出链路；不宣称音频、分段、取消和完整导出完成。

## 完成

- 新增 `dogsc_capture project export-video <project> <output.mp4> <fps>`。
- SourceReader 逐帧读取屏幕媒体；D2D 使用 `FrameSceneEvaluator::render_plan` 和 `D2DFrameCompositor`；输出使用 `MediaWriter`/硬件 H.264 MFT。
- Tauri Project Editor 新增导出路径和“导出”按钮。
- 当前导出是单源视频 prototype：无音频/M4A、无时间线分段/变速映射、无取消/进度/失败恢复。

## 决议

- P4 只标记为 prototype；不能把它当作原版完整导出功能。
- 失败的 WARP `MediaWriter` 路径（`0x80004002`）不作为 fallback；实现改用硬件 D3D11 device 与 D2D compositor，随后真实通过。
- 当前导出优先证明媒体闭环和共用场景求值，下一步再补音频、分段、取消和失败事务。

## 证据

- native clean Release build：成功，无 error/warning。
- CLI `project export-video`：H.264 2560×1600、6 帧、0.199967s；`ffprobe` 通过。
- 最新 Tauri 安装包 GUI：打开真实 H.264 工程，默认导出路径为工程目录 `export.mp4`；点击导出后控制台显示“导出完成：6 帧，0.20s”。
- 导出文件 `ffprobe`：H.264、2560×1600、6 帧、0.199967s。
- CTest：`100% tests passed, 0 tests failed out of 7`。

## 遗留

- 音频/M4A、分段时间线、变速音频映射、导出进度、取消、失败恢复、重新打开验证未完成。
- DXGI 实时预览、完整场景资源和大多数效果 UI 未完成。
- 本轮导出/预览 fixture、安装测试目录和临时日志待按用户确认清理。
