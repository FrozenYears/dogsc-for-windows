# 2026-10-25 第 17 轮：P4 预览音频与变速音频映射

## 目标

补齐 Tauri preview 的音频播放路径，并验证时间线变速后的音频输出时长、采样率和声道契约。

## 完成

- Tauri 启用受限 asset protocol，仅允许 `$APPDATA/**/*`，CSP 增加 `asset:` media source。
- 新增 `prepare_preview_audio` command，在 app data 下创建唯一预览音频缓存路径。
- preview 播放前按工程 capture 能力导出 M4A；有系统/麦克风音频时加载到隐藏 `<audio>`，与 DXGI 视频预览同步播放；无音频工程跳过音频导出。
- preview audio 使用导出后的 timeline 音频，因此剪辑变速和片段拼接由同一 `TimelineMediaPlan` 音频映射处理。
- GUI smoke 增加 `DOGSC_REQUIRE_PREVIEW_AUDIO=1`，要求有音频工程状态出现“音频”。

## 决议

- 不把任意工程路径加入 asset scope；预览音频先导出到受限 app data cache，避免扩大 WebView 文件暴露面。
- 音频导出失败不阻断画面预览，状态显示失败原因；无音频工程不视为失败。
- 预览音频与导出音频共用 native timeline/audio 实现，不在 TypeScript 重做变速采样算法。

## 证据

- `pnpm tauri:build`：TypeScript、Rust Release、NSIS 成功。
- `DOGSC_REQUIRE_DXGI_SURFACE=1 DOGSC_EXERCISE_WINDOW=1 DOGSC_REQUIRE_ZERO_DROPS=1 DOGSC_REQUIRE_PREVIEW_AUDIO=1 node tests/stream_child_lifecycle_smoke.mjs ...`：通过；有音频工程 A 报告 `音频`、30/30 帧、0 丢帧、0 背压；无音频/不兼容音轨工程 B 显示失败原因但不阻断画面。
- 2× 变速工程：native `project edit rate` 将 60s 主片段变为 30s output；`project export-audio` 返回 30.0s、48kHz、2ch；ffprobe 报告 AAC、48kHz、2ch、30.016s 容器时长。
