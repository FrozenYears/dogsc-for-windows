# 2026-10-23 第 03 轮：第二轮 API 检索复核落盘

## 目标

对前两轮遗留的「Windows 上没有 / 不支持 XXX」类断言做二次检索，把推翻与补强的结论写回基线文档，消除规划中与官方文档不符的部分。

## 完成

- `16-open-questions.md` 新增 **D11 第二轮检索复核**：分「维持 / 修正 / 需实测」三类共 6 条修正 + 6 条维持 + 4 条待实测，逐条附来源链接。
- D3（平台门槛）补注：WGC 的 `IGraphicsCaptureSessionN` 编号随 SDK 漂移，运行时必须 `ApiInformation` + QI 探测，不得按接口编号硬判。
- `02-platform-dependency-map.md`：
  - §3.2 透视变换风险由「高」降为「中」，改为内置 `CLSID_D2D13DTransform` / `CLSID_D2D13DPerspectiveTransform`；
  - §3.2 `GaussianBlur` 补 extent 扩张公式 `StandardDeviation × 6 × (DPI/96)`；
  - §3.2 连续圆角补「D2D 无内置 squircle，必须 `ID2D1PathGeometry`」；
  - §3.3 HEVC 补「软件编码器来自 Store 包 Microsoft.HEVCVideoExtension，离线机器首次初始化失败」；
  - §4 整屏采集补「WGC 支持 HDR，首版不做是产品范围决定」；
  - §4 排除语义风险「高」→「中」，改为 `SetWindowExclusionList` 主路径 + 受保护窗口黑块属 OS 行为。
- `15-final-plan.md`：最低系统由 22H2 修正为 **24H2**（与 D3 对齐）；R1 引入 extent 公式；R3 重写为「HEVC 编码器可得性不可保证」；R4 理由修正为「XAML Island 透明/穿透不可靠」而非「做不到」。
- `03-ui-inventory.md`：AppKit 窗口语义一行补透明/穿透的 WinUI 3 限制与三条 issue 证据。

## 决议

- D3/D12 门槛与探测方式：维持 24H2，但**能力探测改为运行时 QI + `ApiInformation`**，不绑定 SDK 编号。
- HUD 走 Win32 的结论不变，**论证依据改写**（可靠性问题，非能力缺失）。
- HEVC 策略：优先厂商硬件 MFT，Store 扩展作为软件回退；离线部署风险记为已知限制。
- HDR：明确列为「产品范围外」，不是「平台不可为」。

## 遗留

- `[INFERENCE]` 厂商 HEVC 硬件 MFT 在无 Store 扩展的干净系统上能否枚举并编码 —— 决定 R3 的实际严重程度，M1 首要实测项。
- `[INFERENCE]` `SetWindowExclusionList` 对 UWP / XAML Island 窗口的生效范围。
- `[INFERENCE]` WGC 窗口采集在最小化/被遮挡时的产出行为。
- `[INFERENCE]` 5K + 多层 blur 的 D2D effect graph 显存峰值与 WARP 回退耗时。
- M0 仍未开工。
