# 2026-10-24 第 06 轮：P1a 项目库与多步编辑历史

## 目标

将上一轮单工程编辑器切片推进为 P1a：项目库枚举/打开/重命名、GUI 主轨重排和可持久化的多步撤销/重做；保留自动保存、脏状态、关闭确认和崩溃恢复为后续 P1b。

## 完成

- `dogsc_capture project list <project-library-root>`：枚举含 `project.json` 的直接子目录，返回标题、路径、创建时间和媒体时长/错误。
- `dogsc_capture project rename <project-directory> <new-name>`：校验 Windows 名称字符，移动整个工程目录，保留 `.project-history` 和媒体文件。
- 将单步 previous/next 改为工程目录下 `.project-history/manifest.json` + 多个不可变状态文件；支持任意工作目录调用。
- `project edit` 新版本自动截断 redo 分支；`project undo` / `project redo` 支持多步历史。
- Tauri 项目编辑器新增：项目库刷新、项目入口、GUI 主轨上移/下移、撤销/重做、工程重命名。
- 项目库条目使用 DOM `textContent` 写入，不把工程标题/错误信息拼进 `innerHTML`。
- 历史状态读取使用工程路径，不依赖 sidecar 当前工作目录。
- 新增永久 CTest 回归脚本 `tests/project_history_smoke.ps1`，覆盖 list、三次编辑、两次 undo、redo、新分支清 redo、rename 和临时目录清理。
