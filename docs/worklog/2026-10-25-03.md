# 2026-10-25 第 03 轮：P3 画布与相机样式 controls

## 目标

在已有 FrameSceneEvaluator/D2D 能力上接入第一批可编辑画面参数：背景预设、留白和摄像头尺寸，并通过 draft session、D2D 预览和 GUI 验收。

## 完成

- Native 新增 `project edit ... style` 草稿操作：
  - `style background <preset>`；
  - `style padding <pixels>`；
  - `style camera-size <normalized-size>`；
  - `style cursor-size <size>`；
  - 同样走 draft、自动保存、history 和原子工程保存。
- Tauri Project Editor 新增画面参数控件和“应用画面参数”按钮。
- 样式参数写入后自动保存，D2D 单帧预览读取更新后的工程。
- 保留当前限制：没有把缺少媒体资源的摄像头/贴图伪造为可见内容。

## 决议

- 本轮只完成 P3 的第一批画布/摄像头参数，不宣称完整效果编辑器完成。
- 背景预设使用 D2D 已验证的五个 pattern 名称；未知预设由 native 拒绝。
- 光标点击、摄像头动态轨、贴图、mosaic/spotlight、屏幕 3D 和开场动画继续后置。

## 证据

- native Release clean build：成功，无 warning/error。
- CLI style smoke：背景 `工程白网格`、padding `160`、camera size `0.4` 写入 `project.json`，D2D composite 命令返回成功。
- 最新安装包 GUI：打开带真实媒体工程，应用背景/留白/摄像头尺寸/光标尺寸 `1.8`，显示“草稿已自动保存”；单帧 D2D 预览显示 `960×600 @ 0.00s`。
- 完整 CTest：`100% tests passed, 0 tests failed out of 7`。
- P4 单源视频导出 prototype 仍通过此前 CLI/GUI/ffprobe 证据；音频/M4A 仍未完成。

## 遗留

- P3 仍缺少光标/点击效果、摄像头运动轨、贴图、mosaic/spotlight、屏幕 3D、运镜和开场动画 UI。
- DXGI surface、硬背压、丢帧统计、无撕裂播放未实现。
- 导出仍是单源无音频 H.264 prototype。
