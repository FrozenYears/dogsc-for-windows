# 2026-10-25 第 09 轮：P3 预览接入光标、点击效果与摄像头布局

## 目标

在已经通过 D2D scene 与 DXGI overlay 的实时预览中接入工程 `pointer.jsonl`、光标点击求值和可选摄像头媒体，保持预览与核心 `FrameSceneEvaluator` / `D2DFrameCompositor` 的同一渲染计划。

## 完成

- `tools/capture_cli/frame.cpp` 增加工程媒体路径安全解析、指针 JSONL 解析、`TimelineMap` 与 `ProjectPointerTrack` 构建。
- 实时预览初始化默认箭头纹理和系统光标 metrics；`system.hidden` 事件不产生光标层，显式光标事件走 `FrameCursorScene`。
- 实时预览读取可选 camera media，按 `startOffset`、`sourceStartTime`、`sourceTimeScale` 映射源时间，上传到同一 D3D11 device，并将 `camera_source_size` 交给 evaluator。
- 实时 `FrameRenderResources` 现在包含 screen、camera、cursor；输出协议增加 `camera`、`cursor`、`click` scene 标记。
- GUI 状态显示 `D2D scene+camera+cursor+click` 等实际层信息。
- `tests/frame_scene_tests.cpp` 增加 camera/cursor/click scene 回归用例，验证 camera source size、pointer track、arrow metrics、click geometry 与规范图层顺序。

## 决议

- 光标素材本轮采用确定性的 44×44 CPU 生成箭头纹理，仅作为 Windows 预览 fallback 资源；不引入外部素材包。
- 摄像头缺失、解码失败时保留 screen-only D2D preview，不阻断工程预览；这是可选媒体资源，不能伪造黑帧。
- 本轮只接入实时预览资源；视频导出循环仍需单独接入 camera/cursor/sticker 资源，不能宣称最终导出已覆盖这些层。

## 遗留

- SourceReader NV12 仍 staging-readback→CPU YUV→BGRA；导出循环尚未复用实时预览的 camera/cursor resources。
- 光标纹理目前是单一箭头 fallback，不包含真实系统光标形状、高清素材、手型/文本/旋转素材。
- 摄像头 preview 已接入基础布局，但摄像头完整素材导入、镜像/形状/阴影的逐像素基准和导出路径仍未验收。
- 贴图资源、mosaic/spotlight、屏幕 3D、运镜与开场 UI 仍未完成。
