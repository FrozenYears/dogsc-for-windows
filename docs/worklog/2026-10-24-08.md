# 2026-10-24 第 08 轮：P2b 持久 SourceReader 预览流 groundwork

## 目标

在 P2a 单帧预览上保留 Media Foundation SourceReader，建立可以连续请求帧的 native stream；不把它误称为 DXGI 实时预览。

## 完成

- `FrameReader` 持有单个 `IMFSourceReader`，复用 RGB32 媒体类型协商和视频处理属性。
- 新增：

```text
dogsc_capture project stream <project.json|project-directory> [max-width]
```

- stream 从 stdin 接受：
  - `F <seconds>`：读取并输出一行 BMP data URI JSON；
  - `Q`：退出；
  - 其他输入返回结构化错误 JSON。
- 单帧 `project frame` 复用同一个 `FrameReader` 实现，未复制解码逻辑。
- 保留路径越界保护、宽度溢出检查和 EOF 错误，不生成伪造帧。

## 决议

- 本轮只标记为 **P2b groundwork**，不是完整实时预览完成。
- stream 已接入 Tauri child，GUI 预览按钮复用持久 SourceReader；增加 30fps 播放头推进和单飞请求，尚未接入 DXGI 共享表面、硬背压和丢帧统计。
- 当前 P2 预览仍显示原始屏幕帧，没有接入 `FrameSceneEvaluator`/`IFrameCompositor` 的背景、光标、摄像头、贴图和运镜层。

## 证据
- native clean Release build：成功，无 error/warning。
- H.264 fixture：`F 0`、`F 0.1` 两次请求，stream exit 0，返回 320×200 两帧，JSON 可解析。
- 单帧 H.264/HEVC、0.1s seek 和 EOF 边界在上一轮已验证。
- 最新 NSIS 安装包约 8.61 MiB；sidecar 848896 字节；从该包 GUI 打开 H.264 工程点击播放，约 0.2 秒后状态为 `960×600 @ 0.20s`、播放按钮恢复“播放”、时间输入约 `0.198`，图片为 BMP data URI。
- P1a 的 7 项 CTest 仍全部通过；当前 CTest 尚未把媒体解码/stream smoke 纳入固定测试目标。

## 遗留

- stream 已进入 Tauri UI；当前 GUI 有 30fps 播放头和单飞请求，但仍不是 DXGI 实时预览。
- 未完成 DXGI surface、硬背压、丢帧监控、无撕裂、共用 D2D 合成和完整拖动/暂停语义。
- 损坏媒体、音视频同步和导出链路仍未完成。

## 下一步

1. 将跨工程切换与 stream child 生命周期 smoke 固化到永久测试；
2. 接入硬背压、丢帧统计和无撕裂验收；
3. 将帧源接入 `FrameSceneEvaluator`/D2D compositor，再建立 DXGI surface。
