# 2026-10-24 第 02 轮：M2a D2D/WARP 验收与 ProRes 性能实测

## 目标

完成 Windows 端核心场景与离屏合成器阶段；以 WARP 实际读回检查完整分层渲染；测量 ProRes 不同分辨率录制行为，并将风险、验证边界与工作状态准确写回文档。

## 完成

- `src/core/` 补齐屏幕构图几何、帧轨、指针轨、自动缩放焦点采样，以及 primary timeline 片段和关联视觉轨道编辑；project JSON 持久化包含新增捕获配置和编辑轨道字段。
- `src/render/d2d/` 实现 WARP/硬件共享的离屏 `IFrameCompositor` 路径，按 background、screen、cursor、spotlight、camera、stickers 顺序合成，接入工程几何、变换、裁切、屏幕装饰/透视、焦点与 spotlight、cursor click、camera、贴图及背景效果。
- D2D smoke 增加六层场景实际读回像素断言；失败合成保留旧的已发布输出。`frame_scene_tests` 增加 pointer spring 双变体上限回归。
- ProRes 用动态 FFmpeg `prores_ks` 编码与 MOV 分片；恢复已完成分段而不重新编码。
- 更新 README、架构与最终方案，区分当前实现、已测范围和仍未通过的里程碑。

## 决议

- ProRes 422 Standard 保留为实现能力，但本机实测表明当前 CPU 编码路径不是实时高分辨率录制可用路径；不对 1080p/1440p 录制宣传实时性能。
- WARP 像素 smoke 通过不是 PNG/PSNR 基准验收；`15-final-plan.md` 原有图像质量阈值仍未宣告通过。
- FFmpeg DLL 的产品分发仍需对应源码、补丁、构建说明、许可 notice 和法律审查；仓库当前构建不等于分发合规已完成。

## 证据

- `cmake --build out/vcpkg-native --config Release --parallel --clean-first`：全部目标从干净状态构建成功，无 MSVC warning/error 输出。
- `ctest --test-dir out/vcpkg-native -C Release --output-on-failure`：6/6 通过，包含核心、捕获时钟、场景几何、时间线编辑、帧场景及 D2D WARP smoke。
- WARP smoke：完整多层场景成功合成，`read_back` 取得 96×64 BGRA 输出；检查不透明背景、透视屏幕、绿色摄像头层、叠加贴图颜色，并保留既有失败路径测试。
- 编码探针：本机 NVIDIA HEVC 与 H.264 MFT 完成各 30 帧 720p30；FFmpeg ProRes Standard 完成 30 帧 MOV 编码。HEVC fragmented MP4 初始化失败，普通 MP4 成功；硬件环境仅代表本机。
- 实录 `--duration 1 --fps 30 --codec prores`：1280×720 报告 35 captured / 30 output frames，wall time 1.746s；1920×1080 报告 5 captured、25 repeated，wall time 2.358s；2560×1440 报告 3 captured、27 repeated，wall time 3.547s。
- 实录 HEVC 2560×1440@30 报告 59 captured、30 output frames；wall time 1.960s。不能据此推导 4K60 或多机性能。
- ProRes 完成段恢复后，`ffprobe` 确认 MOV 含 ProRes Standard / `apcn` / `yuv422p10le` / 1280×720 / 30 帧及 AAC LC 48kHz 双声道 / 1 秒；`ffmpeg -v error ... -f null -` 解码通过。

## 遗留

- ProRes 1080p/1440p 存在明显实时性不足；没有实施 CPU 编码优化或 GPU 硬编码替代，本次记录实测，不隐去缺口。
- 没有固定参考 PNG/PSNR 图像验收，也没有 5K 多层 blur 显存测量或长时渲染性能测试。
- WinUI 3 编辑器、DXGI 实时预览、SourceReader 时间线解码/导出、完整媒体资源生命周期与跨设备采集验收仍未实现。
- 未将 vcpkg FFmpeg 上游源码、精确补丁和重建发布材料纳入仓库；发布前需要处理 LGPL 义务与专利法律评估。
