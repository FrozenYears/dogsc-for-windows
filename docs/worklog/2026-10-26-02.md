# 2026-10-26 第 21 轮：预览音频时钟与 DXGI 诊断断言

## 目标

把已有预览音频和 DXGI smoke 从“资源已加载”提升为播放时钟与呈现诊断的直接行为断言。

## 完成

- `stream_child_lifecycle_smoke.mjs` 在 `DOGSC_REQUIRE_PREVIEW_AUDIO=1` 时读取隐藏 audio 元素的 `currentTime`，等待后要求仍在播放且时间前进。
- 保留 DXGI swapchain、D2D scene、vblank、move/resize、scroll hide/show、跨工程 child 回收和 0 drops/0 backpressure 断言。
- 更新 Preview 与 Export 功能矩阵。

## 决议

- `<audio>` currentTime 推进证明 WebView 音频播放时钟工作，不证明长时视频帧与音频误差已低于一帧。
- `GetFrameStatistics` 与 vblank 只做诊断，不宣告实际屏幕无撕裂；当前用户决定不安装 PresentMon。
- 多轨、麦克风真实资产、长时音画同步和外部显示捕获继续保持 blocked。
