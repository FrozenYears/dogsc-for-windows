# 2026-10-24 第 04 轮：Tauri 项目编辑器纵向切片

## 目标

在现有录制工作区上接入原版编辑器的第一条可运行纵向链路：打开录制工程、展示主时间线、调用核心编辑算法执行分割/裁切/变速/删除，并保留工程恢复副本。

## 完成

- 扩展 `dogsc_capture` 的 `project` 命令：
  - `project inspect <project.json|工程目录>`
  - `project edit <project.json|工程目录> split <output-time>`
  - `trim <segment-id> <left|right> <output-time>`
  - `remove <segment-id>`
  - `move <segment-id> <index>`
  - `rate <segment-id> <playback-rate>`
- 命令复用 `ProjectJson`、`TimelineMap`、`ProjectTimelineEditing`，没有在 Tauri/TypeScript 重复时间线算法。
- `project inspect/edit` 输出稳定 JSON 快照，含片段源/输出区间、播放速度、输出时长及各类剪辑数量。
- 工程编辑采用临时文件 → `project.previous.json` → 原子替换；失败编辑不改动原始 `project.json`。
- Tauri 新增 Project Editor 面板：路径/目录打开、时间线片段显示、分割、左/右裁切、速度、删除；录制成功后自动尝试打开新工程。
- README、最终计划与 Tauri README 同步为 Tauri 编辑器切片的真实边界；重排标注为 CLI 已实现、GUI 尚未接入。

## 决议

- 本轮优先推进 M3 编辑器纵向切片，而不是先做 SourceReader 导出或 DXGI 预览；理由是当前产品可见面仍是录制壳，先建立工程加载和核心编辑闭环。
- Windows 端继续使用独立 `project.json`，不引入 macOS 工程互通；工程目录输入统一解析为目录下的 `project.json`。
- 现阶段不宣称完整编辑器完成：画布、检查器、项目库、实时预览、导出仍属于后续批次。
