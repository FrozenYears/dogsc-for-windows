# 2026-10-25 第 10 轮：P4 主时间线导出映射与 motion editor

## 目标

继续从 P3 收尾进入 P4，先把工程主时间线的编辑后输出域接入视频导出，并补齐 screen motion clip 的编辑入口，避免导出仍把 edited timeline 当 full recording。

## 完成

- `export_video_json` 使用 `TimelineMap` + `TimelineMediaPlan::from_primary` 计算输出 duration 与 output→source 时间映射。
- 主屏导出按 `source_time_at_output_time` 读取素材；遇到真实媒体缺口明确失败，不静默重复或填充错误帧。
- 摄像头导出使用 `TimelineMediaPlan::from_auxiliary`，与主时间线共享输出时钟。
- 新增 `project edit ... screen-motion ...`，支持位置、缩放、X/Y/Z 旋转和 perspective。
- Tauri 工程编辑器增加 screen motion clip 控件并通过 GUI smoke 持久化，预览状态报告 `screen-motion` layer。

## 决议

- 导出时间线先复用已经存在的 `TimelineMediaPlan`，不在 CLI 重新实现分段/变速算术。
- 当前 export 仍是视频单源 prototype；系统音频、麦克风、M4A 尚未伪装为已完成。
- GUI scene smoke 使用工程编辑器真实命令链，避免只测试静态 JSON 改写。
