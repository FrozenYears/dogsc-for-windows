# 2026-10-25 第 11 轮：Tauri editor macOS 风格重排

## 目标

根据用户提供的原版 macOS 参考图，重做 Windows editor 的视觉层与空间结构，不改变现有控件 ID、native command 和预览协议。

## 完成

- 主壳改为 macOS 式浅色窗口：traffic lights、顶部项目工具栏、左侧工具岛、中央画布、右侧检查器、底部时间线。
- 移除原先深色绿色科技仪表盘视觉：改用系统字体、浅灰窗口底、白色半透明浮层、hairline 分隔、系统蓝强调色和低对比阴影。
- preview canvas 使用深色点阵工作区，右侧 inspector 分组为项目、画面、开场、光标、遮罩、贴图。
- timeline 改为播放控制、时间标尺、轨道、片段编辑和导出控制的底部区域。
- recording setup 改为左下角可展开浮动面板，编辑器默认保持干净。
- 保留现有所有功能 ID，包括工程打开、history、scene controls、mosaic、sticker、screen motion、MP4/M4A export 和 cancel。
- 修复重排后重复/缺失 DOM ID，并修复 preview 按钮在新壳层中的启用状态。

## 决议

- 视觉参考采用用户提供的 macOS editor 截图，不复制原项目具体素材；保留 Windows native overlay 与现有信息架构。
- 默认固定为 macOS light editor 观感，避免 Windows 深色系统主题把目标视觉覆盖；录制设置通过悬浮面板保留访问路径。
- 预览 native overlay 不出现在 WebView CDP 截图中；截图中的黑色画布是 WebView 画布容器，实际桌面窗口仍由 DXGI overlay 覆盖。

## 证据

- `pnpm build` 成功。
- `pnpm tauri:build` 成功，Release GUI 与 NSIS 安装包生成。
- GUI smoke：工程 A `D2D scene+screen-frame+opening+screen-motion`，6/6 帧、0 丢帧、0 背压；工程 B `D2D scene+camera`，30/30 帧、0 丢帧。
- 实机截图：`out/smoke/mac-redesign-editor.png`，已确认浅色 macOS toolbar、左侧 rail、中央画布、右侧 inspector、底部 timeline 的结构。

## 遗留

- 录制设置悬浮面板仍需要进一步做成原版 macOS 浮动岛屿的动画与窗口层级语义。
- 右侧 inspector tabs 目前是视觉结构，尚未实现 tab 内容切换。
- native DXGI overlay 不在 WebView 截图中，仍需桌面级截图验证最终叠加视觉。
