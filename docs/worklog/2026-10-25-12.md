# 2026-10-25 第 12 轮：P5 区域选择器与 editor shell 兼容

## 目标

继续补齐 Windows 端选择器能力，同时确保 Mac 风格 editor 重排不破坏原有 native command 与 preview 生命周期。

## 完成

- 增加显示器区域选择按钮和可拖拽区域 picker：在选定显示器尺寸坐标系中拖动、预览选区、确认后写回 `x,y,width,height`。
- 窗口源下区域选择自动拒绝，避免把 display region 参数错误传给 HWND source。
- Mac 风格 editor 重排后补齐所有原有 DOM ID，保留 project history、mosaic、sticker、screen motion、export/cancel 等功能入口。
- 区域 picker GUI smoke 通过，工程生命周期与 DXGI preview smoke 继续通过。

## 决议

- 本轮区域选择器采用 WebView 内可视化显示器坐标面，不伪装成跨显示器 Win32 桌面遮罩；Windows 原生全屏选择 overlay 仍属于后续 P5 增强。
- 保存与读取继续使用现有 `--region` 参数，区域坐标始终相对选定显示器，避免修改 capture CLI 契约。

## 证据

- 新增 macOS 风格 settings modal，支持默认帧率/默认输出目录本机持久化、采集能力预检（显示器/窗口枚举）、简体中文/English preference 与核心按钮标签切换，并显示运行时能力说明；toolbar settings 入口已接入。
- GUI recording marker smoke：在 0.05s 插入 marker，自动保存完成后继续完成工程 A/B preview lifecycle；marker 通过 native `project edit marker` 持久化到 project JSON。
- GUI 输出工程 A 6/6 帧、0 丢帧；工程 B 30/30 帧、0 丢帧。
- `DOGSC_EXERCISE_SETTINGS=1 DOGSC_EXERCISE_REGION=1` 组合 GUI smoke 通过，settings capability check 和 region 四元组写入均完成后 preview lifecycle 继续通过。
- Tauri native tray 已启用：菜单包含“打开 DogSC Studio/退出”，左键恢复并聚焦主窗口；Release/NSIS 构建成功，region/preview lifecycle smoke 通过。
- DOM ID 审计：新增 editor shell 后无缺失引用、无重复 ID。

## 遗留

- 原生桌面级区域选择 overlay、权限向导、托盘、设置窗口、语言切换、录制标记仍未完成。
- 区域 picker 尚未覆盖多显示器坐标原点、DPI 缩放和窗口源区域边界的实机对拍。
