# 2026-10-25 第 04 轮：P5 显示器枚举与区域录制参数

## 目标

补齐录制入口的第一批选择能力：真实枚举显示器，并把已有 native 区域参数接入 Tauri 录制表单。

## 完成

- Tauri 启动时调用现有 `dogsc_capture list`，动态填充显示器名称、索引和分辨率。
- 录制表单新增显示器/窗口采集源切换；窗口模式动态填充 HWND/标题，并禁止显示器索引与区域字段混用。
- 保留 native 对区域坐标、最小尺寸和溢出的严格校验。

## 决议

- 本轮只标记为 P5 partial；没有把固定显示器下拉框伪装成完整窗口/区域选择器。
- 窗口模式先复用 `dogsc_capture list` 的可见窗口枚举；交互式区域框、权限向导、托盘和备忘录继续后置。

## 证据

- 最新 NSIS 包 GUI 启动后动态显示 `主显示器 · 0 · 2560×1600`，窗口列表枚举到 26 个目标。
- 切换采集源为“窗口”后，窗口选择器启用，显示器与区域控件禁用；窗口目标标题包含 `DogSC Studio`。
- `pnpm build`、Tauri 安装包构建和现有 native 7/7 CTest 在此前阶段通过；本轮只改前端启动枚举/参数接线，未改变 native capture 实现。

- 尚未完成屏幕/麦克风/摄像头权限状态页、托盘、备忘录和设置页。
- 本轮生成的 P5 安装目录和测试输出待按用户确认清理。
