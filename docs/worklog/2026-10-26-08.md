# 2026-10-26 第 27 轮：点击自动缩放与打开工程按钮状态

## 目标

## 完成

- native `project edit ... auto-zoom [scale] [transition-duration]`：读取工程 `pointer.jsonl` 的 left/right click，按时间和空间邻近关系聚类，生成自动 origin、spring easing 的 ZoomClip 并写入 `timeline.zoomClips`。

- 自动缩放使用 pointer JSONL 的点击事件，不从画面像素猜测点击位置；点击聚类仅在时间间隔和空间距离满足条件时合并。
- 本轮不伪造完整原版 AutoZoomPlanner 的 legacy repair 和时间线拖拽交互；矩阵明确标记剩余差异。
