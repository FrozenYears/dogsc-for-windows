# 2026-10-25 第 08 轮：P2b DXGI decode surface 与 bounded preview

## 目标

降低预览传输开销，接入真实 Media Foundation/D3D11 decode surface，并限制 WebView 端待呈现帧数量；严格区分 decoder surface 与最终显示 surface。

## 完成

- `FrameReader` 尝试启用 `MF_READWRITE_ENABLE_HARDWARE_TRANSFORMS` 和 `MF_SOURCE_READER_D3D_MANAGER`；成功时请求 NV12，读取 `IMFDXGIBuffer` texture，经 staging readback 和 BT.601/BT.709/BT.2020 YUV→BGRA 转换；设备/媒体类型不支持时回退 RGB32 system-memory reader。
- 读取单 buffer sample 时保留 DXGI buffer，而非先 `ConvertToContiguousBuffer` flatten；GUI stats 明确区分 `DXGI surface` / `CPU fallback`。
- 同一 `FrameReader` 对相邻、向前且间隔不超过 0.5s 的 stream 请求顺序读样本；随机/倒退/远距离 seek 使用 `SetCurrentPosition`。JSON 返回实际 sample PTS。
- SourceReader output 和 D2D composite preview 使用 WIC lossless PNG；`media_preview_smoke.ps1` 验证 PNG signature、H.264/HEVC frame、seek、PTS、stream、EOF 和 composite。
- `FrameReader::read_bgra` 直接返回 top-down BGRA；frame、D2D composite 和 export 复用该 buffer，移除 BMP header、反转行和中间像素 vector copy；WIC factory 按持久 reader 复用。
- Tauri preview 在请求下一帧前等待 `img.decode()` 与两次 RAF；统计 FPS、收到/呈现帧数、解码失败帧和被单飞门拦截的请求数。播放时间以 100ns 时基向下量化；源文件尾帧容差按正常片尾结束。
- `stream_child_lifecycle_smoke.mjs` 可通过 `DOGSC_REQUIRE_DXGI_SURFACE=1` 强制硬件 surface gate，同时覆盖跨工程 child 回收。
- 每个持久 `FrameReader` 缓存一个 WIC factory，避免每帧 COM activation；frame PNG 输出保持无损。

## 决议

- 当前“DXGI surface”证据仅覆盖 **SourceReader decoder NV12 surface ingress**；texture 被回读到 CPU、转换成 PNG 后再交给 WebView。
- 不把 D3D11 staging readback、WebView image decode 或 DWM 默认合成描述为零拷贝/无撕裂。
- H.264/HEVC smoke 在当前设备需要真实 DXGI surface；其它机器可不设置 gate 运行并观测 `CPU fallback`。

## 证据

- Release clean build：`cmake --build out/vcpkg-native --config Release --parallel --clean-first` 成功。
- Release CTest：7/7 passed；H.264/HEVC `media_preview_smoke.ps1` 通过。
- `pnpm tauri:build`：Release GUI 与 NSIS 安装包构建成功。
- GUI 返回 H.264 `960×600 @ 0.17s · 19 fps · DXGI surface · 帧 6/6 · 丢帧 0 · 背压 0`；HEVC `960×600 @ 0.17s · 13 fps · DXGI surface · 帧 6/6 · 丢帧 0 · 背压 0`。工程 A child 在工程 B child 启动前退出。
- H.264 CLI frame 为 960×600 PNG，当前 payload 418,094 bytes；PNG signature `89504E470D0A1A0A`。

## 遗留
- 实测 12–20fps，低于 60Hz 目标；主要路径仍含 GPU→staging readback、CPU YUV 转换、PNG 编码和 WebView image decode。
- 尚未把 D3D11 texture 接入可见 HWND/DirectComposition swapchain；无撕裂、PresentMon/帧时间和跨刷新率验收未完成。
- 当前丢帧统计覆盖 WebView image decode 失败，不覆盖整个 GPU/DXGI presentation queue 的驱动丢帧。
- `FrameReader` 硬件 decoder/device-manager 分支需在更多显卡与 HDR/视频矩阵上回归；当前像素 smoke 未做逐像素/PSNR 对拍。
